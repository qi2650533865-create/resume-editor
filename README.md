# 一页简历

一款本地优先、开箱即用的在线简历编辑器。无需账号或后端服务，打开网页即可编辑，内容保存在当前浏览器中。

## 使用方式

直接打开 `index.html`，或将项目部署到 GitHub Pages。

- 双击要点进入文字编辑，修改后自动保存。
- 点击照片区域可上传 PNG、JPG 或 JPEG 照片（单张不超过 10MB），图片会自动居中裁切并适配证件照区域。
- 拖动经历要点可以调整顺序。
- 选中要点后使用 `Ctrl+C`、`Ctrl+V` 复制，使用 `Del` 删除。
- 使用 `Ctrl+Z` 撤销上一步修改。
- 可创建、复制、重命名、排序或删除多个简历版本。
- `导出PDF` 与 `打印` 分开操作，适配 A4 页面。
- 在线版会定期检查 `version.json`；发现新版本时先保存当前草稿，再由用户确认更新。

## 发布新版本

发布代码改动时，需要同时更新 `app.js` 中的 `APP_VERSION` 和 `version.json` 中的 `version`，两处版本号必须一致。在线版会用这个版本号检测更新，并通过带版本参数的地址刷新所有静态资源。

## 默认模板与隐私

公开源码只包含通用示例模板，不包含维护者的姓名、联系方式、经历或照片。每位访客的修改只保存在自己的浏览器中，彼此不可见。

如果仓库曾提交过个人信息，当前文件删除后仍可能存在于 Git 历史中。公开发布前应清理历史提交，或将当前干净版本推送到一个全新的公开仓库。

所有文本文件均使用 UTF-8 编码。
