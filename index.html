快捷键说明

文字快捷键需要先双击 bullet 进入编辑。

通用操作

Ctrl + S
立即保存
Ctrl + P
打印简历
Ctrl + Z
撤销上一步
Ctrl + Y
恢复上一步
Ctrl + A
全选当前编辑区域
Ctrl + C/X/V
复制、剪切、粘贴

文字编辑与选择

Ctrl + B/I/U
加粗、斜体、下划线
Shift + End
从光标选到本行最右侧
Shift + Home
从光标选到本行最左侧
Ctrl + Shift + ←/→
向左或向右按词选择
Ctrl + ←/→
按词移动光标
Ctrl + Backspace
删除光标前一个词
Shift + Enter
在 bullet 内换行
Esc
退出文字编辑

整条 bullet

Enter
编辑选中的 bullet
Delete
删除选中的 bullet
Ctrl + C/X/V
复制、剪切、粘贴整条 bullet
